# Peruvian Recipes (private)

Private, password-gated Next.js app with Susana's Peruvian recipe collection, transcribed from 151 phone photos (2017)
of a printed Nicolini (Peru) cookbook. The cover and title page were not photographed, so the book title and author are unknown.
Not for public use: the site is `noindex`, robots.txt disallows everything, and every page sits behind a shared password.

* **`recipes_en.json`**: the single source of truth (272 recipes). Each recipe has `id, title_es, title_en, subtitle,
  source{book,pages,photos}, section, course, ingredients[{group,items}], steps[], notes[], uncertain[], translator_notes[],
  cycle_phases[] (empty), fertility_types[] (empty), tags[]`, and `original_es` with the Spanish text. The file also holds the glossary,
  the skipped pages, and the vocabularies for cycle phases and fertility types (the quiz types).
* `recipes_es.json`: the Spanish transcription, generated by `scripts/parse_raw.py` from `raw/*.txt`.
* `raw_en/*.txt`: the hand translation. `python3 scripts/build_en.py` merges it into `recipes_en.json` and validates that
  the ingredient, step and note counts match the Spanish.
* `supabase/schema.sql`: an optional table shape for later. Nothing has been created.

Env (Vercel only, never commit): `RECIPES_PASSWORD`, and `RECIPES_DB_URL`, the Supabase pooler URL(s) for the least-privilege role `recipes_app`.

**Stars:** double-click a card on desktop, or press and hold it on a phone, to star it. The star button does the same. Stars are shared through `public.recipe_stars` in the Supabase project `susana`, which has RLS on and no anon policies; see `supabase/migrations/`. Only `/api/stars` reads or writes them, after it checks the password cookie. The browser keeps a localStorage cache and queues changes when the API is down. The source photos are gitignored and never published.

```
npm install && RECIPES_PASSWORD=dev npm run dev
```
